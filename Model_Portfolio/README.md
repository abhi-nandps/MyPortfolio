# Personal Portfolio Website - Assignment Model

This model is designed for the Web Technology portfolio assignment using only HTML5, CSS3 and JavaScript.

## Folder Structure

- index.html
- css/style.css
- js/script.js
- images/
- resume/

## Before Submission

1. Replace every `YOUR NAME`, college, school, contact and grade placeholder.
2. Add your profile photo to `images/profile.jpg` and replace the profile placeholder in `index.html` with an `<img>` tag.
3. Add project screenshots to the `images/` folder and, if required, update the JavaScript project data.
4. Replace GitHub, LinkedIn, Live Demo and repository URLs.
5. Replace `resume/resume-placeholder.txt` with your actual PDF resume, for example `resume/resume.pdf`, and update the download link.
6. Test all links, filters, modal, dark mode, mobile menu and form validation.
7. Rename the project folder as `RollNo_Name_Portfolio` before pushing it to GitHub.
8. Deploy with GitHub Pages.

## Assignment Features Included

- Semantic HTML5: header, nav, main, section, article, aside, footer
- About, Skills, Projects, Internship, Education and Contact sections
- Lists, description lists and tables
- Internal and external hyperlinks
- Profile/project image placeholders
- Flexbox and CSS Grid
- Sticky navigation and fixed scroll-to-top button
- Hover effects and shadows
- Responsive media queries
- Projects stored in a JavaScript array of objects
- Dynamic project rendering using map and DOM manipulation
- Project filtering
- Mobile navigation toggle
- Dark/light theme switch
- Project details modal
- Regex contact-form validation
- localStorage for theme and last validated message
- ES6+ JavaScript: const/let, arrow functions, template literals, map/filter/forEach, destructuring
